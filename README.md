# TEAMO stats-bot

Маленький сервис, который:
1. По расписанию пишет в ваш Telegram-чат команду `Стата вся` (или другую, см. `STATS_COMMAND`).
2. Слушает ответ бота Iris в этом же чате и парсит топ-10 + «Всего сообщений».
3. Отдаёт последние сохранённые данные по `GET /api/stats` в формате JSON, который использует виджет на сайте.

## 1. Создать Telegram-бота

1. Напишите **@BotFather** → `/newbot`, задайте имя, получите `BOT_TOKEN`.
2. Обязательно отключите privacy mode, иначе бот не увидит сообщения Iris:
   `/setprivacy` → выберите вашего бота → **Disable**.
3. Добавьте бота в ту группу, где стоит Iris. Права администратора не обязательны, но с ними надёжнее (на случай ограничений чата).

## 2. Узнать CHAT_ID

Самый простой способ — временно добавить в группу бота **@getidsbot** (или **@userinfobot**), он покажет ID чата (отрицательное число вида `-100xxxxxxxxxx`). После этого можно удалить его из группы.

## 3. Задеплоить на Railway

1. Загрузите содержимое этой папки в GitHub-репозиторий (или используйте Railway CLI `railway up` прямо из папки).
2. В Railway: **New Project → Deploy from GitHub repo** (или Empty Project → Deploy from local).
3. В **Variables** добавьте переменные из `.env.example`:
   - `BOT_TOKEN`
   - `CHAT_ID`
   - `IRIS_USERNAME` (username Iris в вашем чате, без @)
   - `CRON_SCHEDULE` (по умолчанию раз в 6 часов)
   - `STATS_COMMAND`
   - `ALLOWED_ORIGIN` — домен вашего сайта (например `https://teamo.ru`), чтобы фронтенд мог делать запросы
4. Railway сам определит `npm start` из `package.json` и задеплоит.
5. После деплоя Railway выдаст публичный URL вида `https://teamo-stats-bot-production.up.railway.app`.

## 4. Проверка

- `GET /health` — проверка, что сервис жив.
- `GET /api/refresh` — вручную попросить бота прислать команду в чат прямо сейчас (полезно для первого теста, не защищайте пока паролем, но не публикуйте ссылку широко).
- Подождите ответ Iris (обычно секунды), затем `GET /api/stats` должен вернуть JSON вида:

```json
{
  "top": [
    { "place": 1, "name": "отец кф", "count": 581 },
    { "place": 2, "name": "DESERVELLER", "count": 556 }
  ],
  "total": 2382,
  "updatedAt": "2026-08-18T12:00:00.000Z"
}
```

## 5. Важно

- Если формат ответа Iris у вас чуть отличается (другое тире, другая формулировка «Всего сообщений»), поправьте регулярки в `parseIrisMessage` в `index.js`.
- Данные сохраняются в `stats.json` рядом с сервисом, чтобы не терялись при рестарте контейнера — Railway при передеплое стирает файловую систему, но новые данные придут при следующем запуске cron.
- Если хотите более частое обновление — просто измените `CRON_SCHEDULE`.
